# ThinkSync Project Skills & Guidelines

## 1. UI/UX Pro Max Skill
- Reference: https://github.com/nextlevelbuilder/ui-ux-pro-max-skill
- Always design ultra-modern, production-ready, clean UI components.
- Use high-converting layouts, sleek typography, micro-interactions, responsive grids, and modern color palettes.

## 2. Framer Motion Animation Skill
- Integrate `framer-motion` for all React UI animations.
- Add smooth entrance animations, hover states, layout transitions, and scroll-triggered animations for hero sections, cards, and buttons.

## 3. Superpowers Agent Workflow Skill
- Reference: https://github.com/obra/superpowers
- Act as an autonomous, high-powered software engineer agent.
- Plan complex refactoring before writing code, break down steps, double-check file paths, and test build/API configurations step by step.
